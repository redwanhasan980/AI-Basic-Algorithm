===============================================================================
              N-QUEEN PROBLEM USING GENETIC ALGORITHM
                    Step-by-Step Explanation
===============================================================================

PROBLEM OVERVIEW:
Place N queens on an N×N chessboard such that no two queens attack each other.
Queens attack horizontally, vertically, and diagonally.

WHY GENETIC ALGORITHM?
- N-Queen is NP-hard for large N
- Traditional backtracking becomes slow
- Genetic Algorithm provides good solutions quickly
- Works well for optimization problems

===============================================================================
                    GENETIC ALGORITHM STEPS
===============================================================================

STEP 1: REPRESENTATION (Chromosome Encoding)
--------------------------------------------
Chromosome = Array of N integers
- Index i = Column number
- Value at index i = Row number of queen in column i
- Example for 4-Queen: [1, 3, 0, 2]
  Column 0: Queen at row 1
  Column 1: Queen at row 3
  Column 2: Queen at row 0
  Column 3: Queen at row 2

Visualization:
    0 1 2 3
  0 . . Q .
  1 Q . . .
  2 . . . Q
  3 . Q . .

ADVANTAGE: No two queens in same column (guaranteed by representation)

STEP 2: FITNESS FUNCTION
-------------------------
Goal: Maximize non-attacking queen pairs

Fitness = Total possible pairs - Number of attacking pairs
        = n(n-1)/2 - attacks

Count attacks:
a) Same row: chromosome[i] == chromosome[j]
b) Diagonal: |chromosome[i] - chromosome[j]| == |i - j|

Example for 4-Queen:
- Maximum fitness = 4×3/2 = 6 (6 pairs of queens)
- If 2 pairs attack each other: fitness = 6 - 2 = 4
- Perfect solution: fitness = 6

STEP 3: INITIALIZE POPULATION
-------------------------------
Create POPULATION_SIZE random individuals

For each individual:
1. Generate random chromosome (N random numbers 0 to N-1)
2. Calculate fitness
3. Add to population

Example Population (N=4):
Individual 1: [2, 0, 3, 1] fitness = 5
Individual 2: [1, 1, 2, 0] fitness = 3
Individual 3: [3, 1, 2, 0] fitness = 4
...

Population Size: Typically 50-200 individuals

STEP 4: SELECTION (Tournament Selection)
-----------------------------------------
Select parents for reproduction using tournament selection:

1. Randomly pick 2 individuals from population
2. Compare their fitness
3. Select the one with HIGHER fitness as parent
4. Repeat to get second parent

Why Tournament Selection?
- Simple and efficient
- Gives preference to fitter individuals
- Still allows weaker individuals a chance

Example:
Pick Individual 1 (fitness=5) vs Individual 2 (fitness=3)
→ Select Individual 1 as parent

STEP 5: CROSSOVER (Recombination)
----------------------------------
Combine two parents to create offspring

Single-Point Crossover:
1. Choose random crossover point
2. Take genes before point from parent1
3. Take genes after point from parent2

Example (N=8, crossover point=4):
Parent 1: [2, 5, 1, 3, | 7, 0, 6, 4]
Parent 2: [1, 6, 0, 2, | 4, 7, 5, 3]
          ---------------+-------------
Child:    [2, 5, 1, 3, | 4, 7, 5, 3]

Purpose: Combine good traits from both parents

STEP 6: MUTATION
-----------------
Randomly modify genes to maintain diversity

For each gene in chromosome:
- With probability MUTATION_RATE (e.g., 0.1 or 10%)
- Replace with random value (0 to N-1)

Example (MUTATION_RATE = 0.1):
Before: [2, 5, 1, 3, 4, 7, 5, 3]
         ^           ^
After:  [6, 5, 1, 3, 2, 7, 5, 3]
        (mutated)   (mutated)

Purpose:
- Explore new solutions
- Escape local optima
- Maintain genetic diversity

STEP 7: ELITISM
----------------
Preserve best individuals from current generation

1. Sort population by fitness
2. Keep top 10% (elite) directly in next generation
3. They don't undergo crossover/mutation

Why Elitism?
- Ensures best solutions aren't lost
- Guarantees monotonic improvement
- Speeds up convergence

STEP 8: REPLACEMENT (Create New Generation)
--------------------------------------------
Build new population:

1. Add elite individuals (top 10%)
2. Fill remaining slots:
   - Select two parents
   - Crossover to create child
   - Mutate child
   - Add child to new population
3. Repeat until population is full
4. Replace old population with new population

STEP 9: TERMINATION
-------------------
Stop when:
a) Perfect solution found (fitness = n(n-1)/2)
b) Maximum generations reached
c) No improvement for many generations (optional)

Check each generation:
- Calculate fitness of best individual
- If fitness == max_fitness → Solution found!
- Otherwise continue to next generation

STEP 10: OUTPUT SOLUTION
-------------------------
Display the best solution found:
- Print board configuration
- Show queen positions
- Display fitness score
- Show number of generations
