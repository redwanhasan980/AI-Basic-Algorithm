We can solve n queen problem using backtracking.
But the problem with backtracking is that it may explore many doomed paths
and when the value of n get large it may take a long time to find a solution or
to determine that no solution exists.


♟️ 1. The N‑Queens Problem — Quick Recap
Place N queens on an N × N chessboard such that no two queens attack each other.
This means:
No two queens share the same row
No two queens share the same column
No two queens share the same diagonal
The problem is a classic Constraint Satisfaction Problem (CSP).

🧩 2. Backtracking Approach
✅ How it works:
Place queens one by one (e.g., one per row).
For each row:
Try each column.
Check if placing a queen there conflicts with any previously placed queens.
If conflict → backtrack and try a different column.
Continue until all queens are placed.
🚫 Problems with Backtracking
Problem	Description	Why It Happens
1. Exponential Time Complexity	Backtracking explores all possible queen placements systematically. For large N, this becomes huge (combinatorial explosion).	Each queen has N possible positions. The search tree grows as O(N!) in the worst case.
2. Repeated / Redundant Search	Many partial arrangements lead to the same conflicts — but backtracking still explores them separately.	The algorithm doesn’t learn from previous mistakes.
3. Poor Scalability	Works fine for small N (like 8), but becomes impractical for large N (>30 or 50).	Branching factor and recursion depth grow rapidly.
4. Deterministic Behavior	Backtracking explores one branch at a time in a rigid order.	It can get “stuck” in deep paths before finding alternatives.
5. Localized Failure Propagation	A wrong early choice forces much later backtracking, wasting time.	No global view — purely depth‑first.
In short: Backtracking is complete (guaranteed to find a solution or prove none exists),
but for large N it’s too slow and memory‑intensive.

🧬 3. Genetic Algorithm (GA) Approach
✅ How it works:
Genetic Algorithms are population-based, probabilistic search techniques inspired by evolution.

Each individual represents a candidate solution (e.g., queen placements across the board).
Each gene represents position of a queen (e.g., column for each row).
A population of individuals evolves using:
-> Selection – keep better solutions (lower conflict count)
-> Crossover – combine parts of two good solutions
-> Mutation – randomly change parts to explore new possibilities
Over generations, fitter solutions dominate → leading to conflict-free board arrangements.
📊 Example Representation (for N = 8)
An individual solution could be represented as:
[1, 5, 8, 6, 3, 7, 2, 4]
→ means:
Queen in row 1 is in column 1,
Queen in row 2 is in column 5, etc.

⚔️ 4. How GA Addresses Backtracking Problems
Backtracking Problem	Genetic Algorithm Solution / Advantage
1. Exponential search space	GAs sample the search space probabilistically instead of exploring systematically. They skip vast numbers of impossible configurations.
2. Redundant exploration	GAs maintain a population of diverse solutions, exploring multiple regions of the search space simultaneously, reducing redundancy.
3. Poor scalability	GAs scale much better — even for large N (hundreds or thousands). Not guaranteed to find an optimal solution, but finds a valid one quickly.
4. Deterministic behavior	GAs use randomness (mutation, crossover) → can escape getting “stuck” in specific regions of the solution space.
5. Localized backtracking	GAs don’t backtrack. They learn globally from the entire population and evolve toward better solutions collectively.
6. No learning in backtracking	GAs preserve useful partial structures (through crossover and selection). This acts as “learning” which backtracking lacks.
